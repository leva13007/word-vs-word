# Word vs Word

Живий каталог пар (і груп) близьких за значенням слів. Пояснює різницю у використанні — як в інженерних контекстах (🔧 IT), так і в загальній англійській (📖 general).

## Для кого цей проєкт

- розробники, яким важливо точно формулювати причини, наслідки та рішення
- всі, хто бачить що слова перекладаються однаково, але відчуває що вживаються вони по-різному
- люди, які думають системно, а не "словниково"

## Як організовано

- кожен файл `NNNN-keyword.md` присвячений одному кластеру слів;
- контекстний тег над вступом: `🔧 IT`, `📖 general`, або обидва — показує де застосовується матеріал;
- кожен файл має секцію `## Для картки` в кінці — як безпечно позначити нюанс в Anki;
- конвенція: `(контекст)` — безпечний контекст; `(~підказка~)` — підказка, **не** перекладати дослівно; `(A|B)` — альтернативи.

## Як додавати нові сторінки

1. Скопіювати `_template.md` у новий файл `NNNN-topic.md`.
2. Замінити заповнювачі, вибрати контекстний тег, заповнити секцію `## Для картки`.
3. Додати запис у таблицях нижче.
